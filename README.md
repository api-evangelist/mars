# Mars (mars)

Mars, Incorporated is one of the world's largest privately held companies, producing confectionery, pet food, food, and providing veterinary care. The company owns iconic brands including M&M's, Snickers, Twix, Milky Way, Skittles, Wrigley, Orbit, Extra, Pedigree, Whiskas, Royal Canin, IAMS, and Sheba, and operates Mars Petcare clinical brands including Banfield Pet Hospital, VCA Animal Hospitals, BluePearl, and Antech Diagnostics. Mars operates in over 80 countries. Mars does not currently publish a public developer API or developer portal.
